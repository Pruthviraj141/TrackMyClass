# Design Tokens

**Brand Identity for TrackMyClass**

- **Primary Color**: Deep Royal Blue (`hsl(221.2 83.2% 53.3%)`). Trustworthy, authoritative, and academic.
- **Background**: Very light gray (`hsl(220 14% 96%)`) instead of pure white to reduce glare, especially for the admin monitor console.
- **Typography**: Inter (or system-ui fallback). Clean, geometric, readable at small sizes on data-dense tables.
- **Border Radius**: 0.75rem (12px). Rounded enough to feel modern, but not so rounded it feels like a toy.
- **Surface Elevation**: Subdued shadow system. Only floating elements (like the canvas overlay stats) get drop shadows. Forms and panels sit flush or use thin 1px borders.

This design deliberately avoids the generic "AI dashboard" look (neon violet on pitch black) in favor of a clean, high-contrast, ops-console aesthetic.
